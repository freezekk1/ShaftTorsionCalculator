# ShaftTorsionCalculator

Расчет стержня (вала) на кручение. Программа определяет внутренние крутящие моменты,
касательные напряжения и углы закручивания на участках стержня и строит эпюры.

* **Этап 1** - консольное приложение: ввод участков и граничных условий командами.
* **Этап 2** - рисование расчетной схемы и эпюр средствами Qt (`QPainter`).

Без установленного Qt программа собирается и работает как консольная (этап 1).

## Сборка

Нужны CMake ≥ 3.16 и компилятор C++17. Для эпюр - Qt 6 (или Qt 5) с модулем Widgets.

```bash
cmake -S . -B build
cmake --build build
./build/ShaftTorsionCalculator
```

Если Qt установлен не в системные пути, укажите его:

```bash
# macOS (Qt из онлайн-установщика или Homebrew)
cmake -S . -B build -DCMAKE\_PREFIX\_PATH=\~/Qt/6.x.x/macos
# или: -DCMAKE\_PREFIX\_PATH=$(brew --prefix qt)
```

Проект открывается в Qt Creator как обычный CMake-проект (File → Open File or Project →
`CMakeLists.txt`). Параметр `-DWITH\_QT=OFF` принудительно отключает Qt, `-DWITH\_QT=ON`
требует его наличия. Тесты: `ctest --test-dir build`.

## Работа с программой

Запуск без параметров начинает **пошаговый ввод**: программа спрашивает, где заделка, модуль сдвига G,
число участков и параметры каждого, затем сама считает и открывает эпюры. Enter без ввода - значение
по умолчанию (в квадратных скобках). После этого работает режим команд (`help` - справка,
`example` - пример, `wizard` - ввести данные заново).

Входные данные такие же, как на [sopromat.xyz](https://sopromat.xyz/projects/torsion):

* заделка в начале и/или в конце, модуль сдвига G (МПа);
* участки слева направо: длина (м), форма сечения, размер (см), сосредоточенный момент **M в начале
участка** (Н·м), распределенный момент **m** (Н·м/м);
* момент в конце вала (Н·м).

Формы сечения:

|Форма|Размер|Дополнительный параметр|
|-|-|-|
|круг (`circle`)|диаметр d|-|
|прямоугольник (`rect`)|меньшая сторона b|h/b ≥ 1|
|труба (`tube`)|наружный диаметр D|d/D от 0 до 1|

|Команда|Действие|
|-|-|
|`wizard`|пошаговый ввод, расчет и эпюры|
|`fix start\|end\|both\|none`|заделка в начале / в конце / с обеих сторон / нет|
|`g <МПа>`|модуль сдвига G|
|`mend <Н·м>`|момент в конце вала|
|`add circle <L> <d> \[M] \[m]`|участок-круг|
|`add rect <L> <b> <h/b> \[M] \[m]`|прямоугольник|
|`add tube <L> <D> <d/D> \[M] \[m]`|труба|
|`edit <n> ...` / `del <n>` / `clear`|изменить / удалить участок / удалить все|
|`show`, `calc`|показать данные, выполнить расчет|
|`plot`|эпюры в окне Qt (кнопка «Сохранить в PNG...»)|
|`png <файл.png>`|эпюры в файл|
|`save <файл>` / `load <файл>`|сохранить / загрузить данные (текст из этих же команд)|
|`example`|загрузить пример с сайта|
|`quit`|выход|

## Расчетные формулы

* Крутящий момент на участке (метод сечений, по правой отсеченной части): T = сумма внешних моментов
правее сечения (сосредоточенные M, момент в конце вала и распределенные m·ds). При m ≠ 0 момент
меняется по участку линейно: T(s) = T(0) − m·s.
* Круг: Jp = πd⁴/32, Wp = πd³/16. Труба: Jp = πD⁴(1 − c⁴)/32, Wp = πD³(1 − c⁴)/16, c = d/D.
* Прямоугольник (h ≥ b): τmax = T/(α·h·b²), Jk = β·h·b³; коэффициенты α, β берутся из таблицы
по h/b с линейной интерполяцией (h/b = 2: α = 0.246, β = 0.229).
* Касательные напряжения: τ = T/Wk (Wk = Wp для круга и трубы).
* Угол поворота сечения: φ(s) = φ₀ + (T(0)·s − m·s²/2)/(G·Jk); угол закручивания участка
Δφ = T\_ср·L/(G·Jk). φ = 0 в заделке.
* Статическая неопределимость (заделки с обеих сторон): реакция в конце X находится из условия
φ(L) = 0, то есть Σ (T⁰ᵢ,ср + X)·Lᵢ/Jkᵢ = 0.
* Если заделок нет, внешние моменты должны уравновешиваться (Σ M = 0).

Проверка по примеру с сайта (см. выше) совпадает с его результатами; в `tests/test\_solver.cpp` эти
значения проверяются автоматически.
